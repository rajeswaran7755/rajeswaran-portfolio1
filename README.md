# Automotive Embedded Engineer Portfolio

A responsive static portfolio for Rajeswaran Gajendran, with a clean white/charcoal automotive ECU-inspired design.

## Files
- `index.html` — portfolio content and layout
- `styles.css` — responsive styling and CSS-based ECU / project illustrations
- `script.js` — mobile navigation
- `assets/Rajeswaran_Gajendran_Resume.pdf` — résumé PDF, if available in the source files at packaging time

## Preview
Open `index.html` in a browser.

## Deploy to GitHub Pages
1. Extract the ZIP.
2. Upload `index.html`, `styles.css`, `script.js`, and `README.md` to your repository root.
3. Upload the PDF into a folder named `assets` at the repository root.
4. Open **Settings → Pages**. Choose **Deploy from a branch**, `main`, and `/(root)`.
5. Wait for the Pages deployment to finish.

Review all dates, experience statements, contact details and education wording before publishing. If the résumé PDF is not included, place your latest PDF at `assets/Rajeswaran_Gajendran_Resume.pdf`.
